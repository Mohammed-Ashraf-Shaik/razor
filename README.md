# 💳 Razorpay Landing Page Clone

A responsive, modern fintech front-end clone of **Razorpay**, India's top full-stack payments and banking platform. This project recreates the flagship website experience with rich typography, interactive mega menus, 3D hero artwork, and micro-interactions.

## ✨ Features & Highlights

- **⚡ Interactive Multi-Tier Mega Menus**:
  - **Payments Stack**:
    - *Payment Aggregator* — Seamless collection for businesses.
    - *Payment Gateway* — Web & App checkout flows.
    - *Payment Links & Pages* — Instant pay links and branded pages.
    - *QR Codes & UPI* — Complete UPI stack integration.
    - *Magic Checkout* — Conversion booster with reduced RTOs.
    - *Subscriptions & Instant Settlement* — Automated recurring billing.
    - *Optimizer* — Multi-gateway routing and optimization.
  - **Banking Suite (RazorpayX)**:
    - *Current Accounts*, *Payouts*, *Corporate Cards*, and *Payroll*.

- **🎨 Modern Fintech Aesthetic**:
  - Razorpay's signature blue-and-white visual palette with custom gradients.
  - High-res 3D hero visual illustration (`razorpay_hero_3d.png`).
  - Google Fonts Inter integration for crisp typography.
  - FontAwesome 6 icon set for fintech product badges.

- **📱 Fully Responsive Design**:
  - Adaptable layout engineered for desktop, tablet, and mobile screens.
  - Interactive navigation controls powered by `ras.js`.

- **🛡️ Trust & Security Elements**:
  - Security badges representing PCI-DSS Level 1 compliance, ISO certifications, and end-to-end encryption guarantees.
  - Partner showcase and social proof statistics.

## 🚀 Getting Started

### Prerequisites
A modern browser such as Google Chrome, Firefox, Safari, or Microsoft Edge.

### Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/Mohammed-Ashraf-Shaik/razor.git
   ```
2. Navigate into the project folder:
   ```bash
   cd razor
   ```
3. Open `index.html` in your browser:
   - On Windows:
     ```powershell
     start index.html
     ```
   - Or open using VS Code's **Live Server** extension for real-time live reloading.
